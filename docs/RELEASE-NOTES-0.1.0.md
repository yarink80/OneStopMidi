# OneStopMidi 0.1.0

First release.

- MIDI file player for `.mid`, `.midi`, `.kar`, `.smf` and `.rmi`: play, stop, pause, move by bar, loop between locators, cue slider.
- Tempo change (%), exact BPM for single-tempo songs, and transpose ±24 semitones that leaves drum channels alone.
- Playlists with playlist mode and autoplay, Recently Played, search across playlists, drag & drop, and import/export of `.txt`, `.m3u`, `.m3u8` and `.jpl`.
- 16-channel mixer: volume, pan, reverb, chorus, solo, mute and General MIDI instrument picker.
- Karaoke view with chord symbols, both embedded in the file and worked out from the notes.
- Edit a range (cut, copy, paste, delete) with undo/redo; save as format 0 or 1.
- Multiple MIDI output ports with per-channel routing.
- **Every keyboard shortcut can be remapped**, including the arrow keys, Enter and NumPad Enter (as a separate key), with a "Foot pedal / remote" preset.
- **Playlist on startup:** open the last-used or a specific playlist, then select, load or play a song automatically; `--playlist` on the command line.

Download `OneStopMidi-Setup.exe` below (per-user install, no admin), or `OneStopMidi-Portable.zip` to run without installing.
